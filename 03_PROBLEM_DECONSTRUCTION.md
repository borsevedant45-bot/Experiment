# 03 PROBLEM DECONSTRUCTION

STATUS: LOCKED
DATE: 2026-10-04

## PURPOSE
Convert boring or cognitively heavy delivery moments into useful experience opportunities.

## OPPORTUNITY MAP
| Functional moment | Pain/risk | Design opportunity |
|---|---|---|
| Discovery | choice overload | visual craving field |
| Search | blank utility state | search behaves like an intent lens |
| Restaurant choice | card sameness | restaurant becomes a distinct counter/world |
| Menu | long scan | meal composition groups information |
| Add | weak feedback | food physically joins tray |
| Cart | transactional checkpoint | packed collection/tray |
| Checkout | bureaucratic interruption | calm packing/sealing station |
| Confirmation | static success | ticket prints / pack seals |
| Waiting | dead time | anticipation through journey state |
| Tracking | generic status/map | order object travels |
| Delivery | abrupt endpoint | package settles into arrival state |
| Reorder | repetitive search | prior order reconstructs directly |

## CORE TRANSLATIONS
Search → **Craving Lens**
Browse → **Food Field**
Restaurant → **Kitchen Counter**
Add → **Place on Tray**
Cart → **Packed Collection**
Checkout → **Seal the Order**
Confirmation → **Ticket Issued**
Tracking → **Journey Line**
Delivery → **Arrival**

## COGNITIVE LOAD RULE
Flourish is permitted only when it improves discovery, hierarchy, feedback, orientation, storytelling or delight. Checkout, payment, address entry and recovery states remain calmer and more conventional.

## TRUST RULE
Names, prices, quantities, fees, totals, ETA, address and primary actions never disappear into illustrations.

## REJECTED DIRECTIONS
- Every state equally animated.
- Decorative interaction that delays a task.
- Metadata hidden inside artwork.

## LOCKED DECISIONS
The creative system is a layer over a dependable commerce flow, not a replacement for it.

## DEPENDENCIES
04–10.

## OUTPUT
Functional-to-experiential translation map.
