# 13 PHYSICAL INTERACTION

STATUS: LOCKED
DATE: 2026-10-04

## PHYSICAL METAPHOR MAP
| Digital action | Physical behavior | Required feedback |
|---|---|---|
| Click | press/stamp/place | immediate tactile response |
| Hover | object notices attention | tiny lift/tilt |
| Focus | spotlight/ink edge | persistent visible focus |
| Drag | pick up object | direct tracking |
| Scroll | move across counter | environment reframes |
| Swipe | move tray/sheet | direct travel + settle |
| Select category | change kitchen station | spatial reframe |
| Add to cart | place on tray | item travels + count updates |
| Remove | lift off tray | clean exit + total update |
| Quantity + | add portion | local meal recomposes |
| Quantity − | remove portion | reverse assembly |
| Checkout | pack/fold | calm transition |
| Confirm | seal/print ticket | decisive state change |
| Track | follow package/ticket | journey progression |
| Completion | arrival/settle | stable success state |

## RULES
1. Metaphor never replaces semantic feedback.
2. Mouse, touch and keyboard reach equivalent states.
3. Drag is never required for critical tasks.
4. Gestures always have a conventional equivalent.
5. Metaphor cannot change meaning unpredictably.

## POINTER
Pointer attraction/reaction may affect decorative/food objects in a limited radius but must not disturb readable content or primary controls.

## TOUCH
Increase hit targets and reduce overlapping decorative elements. No hover-only meaning.

## ERRORS
Error may use a “blocked station” or misplaced-label visual cue as a secondary treatment, but error text/recovery remains conventional.

## REJECTED DIRECTIONS
Gesture-only navigation; secret affordances; drag-only ordering.

## LOCKED DECISIONS
Physical behavior is an interpretive layer over conventional, accessible input semantics.
