# 06 DESIGN PRINCIPLES

STATUS: LOCKED
DATE: 2026-10-04

## 1. FOOD IS THE PROTAGONIST
**Why:** appetite is the product's emotional trigger.
**Use:** food receives the strongest visual emphasis.
**Violation:** decoration dominates the dish/action.

## 2. THE ORDER IS A PHYSICAL OBJECT
**Why:** forms alone make ordering feel bureaucratic.
**Use:** assemble, pack, seal, issue, travel.
**Violation:** cart/checkout abruptly becomes generic dashboard UI.

## 3. MOTION EXPLAINS STATE
**Why:** animation is part of UX.
**Use:** each major state has a distinct transition language.
**Violation:** animation loops without information or delight.

## 4. ONE WORLD, MANY STATES
**Why:** coherence is more premium than novelty-per-screen.
**Use:** kitchen, plate, wrapper, ticket and journey share the same DNA.
**Violation:** every route looks like a different design experiment.

## 5. VISUAL EXCESS NEEDS A QUIET COUNTERPOINT
**Why:** pacing creates perceived craft.
**Use:** spectacle → calm → task.
**Violation:** continuous sensory noise.

## 6. METADATA NEVER HIDES BEHIND THE METAPHOR
**Why:** commerce needs confidence.
**Use:** prices, totals, ETA and errors stay explicit.
**Violation:** artwork replaces essential semantics.

## 7. IMPERFECTION IS CONTROLLED
**Why:** hand-drawn character differentiates the system.
**Use:** consistent irregularity tokens.
**Violation:** random inconsistent asset quality.

## 8. COLOR IS A LANGUAGE
**Why:** bold color can guide attention.
**Use:** fixed semantic roles for accents.
**Violation:** arbitrary accent changes.

## 9. PHYSICAL METAPHOR, DIGITAL PRECISION
**Why:** playful should still feel reliable.
**Use:** elastic object motion, deterministic controls.
**Violation:** interactions feel slippery or ambiguous.

## 10. BUILD FROM MODULAR PARTS
**Why:** motion requires separable object layers.
**Use:** food, garnish, steam, shadow, wrapper, label can animate independently.
**Violation:** every scene is a flattened asset.

## REJECTED GENERIC ADVICE
“Make it modern.” “Use vibrant colors.” “Keep it simple.” These are insufficient without product-specific rules.

## LOCKED DECISIONS
All later artifacts are evaluated against these ten laws.
