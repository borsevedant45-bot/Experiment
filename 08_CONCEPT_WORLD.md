# 08 CONCEPT WORLD

STATUS: LOCKED
DATE: 2026-10-04

## PURPOSE
Formalize the selected Living Kitchen direction into a coherent universe.

## THE WORLD
A sparse 2D illustrated kitchen set that wakes when the user begins looking for food. The environment behaves like a helpful stagehand: counters, plates, labels, packaging and tickets move to support the user’s intent.

## THE METAPHOR
> **A food order is a small physical choreography from craving to packed meal to journey.**

## THE CAST
Food dishes, ingredients, plates/bowls, packaging, labels, tickets/receipts, utensils, counter surfaces, steam/heat marks and journey lines.

Food objects are the protagonists; props support them.

## THE RULES
1. Every recurring object has a stable silhouette.
2. Every moving object has a resting state.
3. Object motion can be imperfect; information motion must remain precise.
4. A state change should move/reveal/recompose an existing object whenever possible.
5. No route becomes a separate visual universe.
6. Backgrounds remain quiet enough for food and content hierarchy.
7. Checkout/payment/error states suppress theatrical motion.
8. The first interaction may be memorable; repeated interactions must become faster.

## SIGNATURE BEHAVIOR
**Kitchen cause-and-effect:** an important user action produces local, related responses. Add a dish → plate shifts. Increase quantity → meal recomposes. Confirm → package seals/ticket prints. Track → ticket becomes journey marker.

## VISUAL VOICE
“Hand-drawn editorial stagecraft” rather than “cartoon UI.” Humor comes from timing and object behavior, not mascot faces.

## CONTRAST WITH STANDARD DELIVERY UI
Ordinary delivery flows are mostly repeated cards and utility screens. Here, one physical world carries the complete journey while preserving the same information hierarchy underneath.

## REJECTED DIRECTIONS
3D kitchen simulation; photoreal food; mascot-led interface; dense illustrated scenes; giant infinite canvas.

## LOCKED DECISIONS
Living Kitchen is the creative north star. Food/order objects recur across every stage.
